# WorldBox — глобальная песочница от палеолита до космоса

Симулятор мира, в котором народы сами развиваются от каменных орудий до орбитальных колоний.
Игрок — бог: наблюдает, вмешивается стихиями и решениями, но не управляет напрямую.

## Стек

- **C# + .NET** и **MonoGame 3.8.x** — фреймворк, на котором сделаны Stardew Valley, Celeste, Bastion, Barotrauma, Streets of Rage 4.
- Результат сборки — настоящий **.exe** под Windows, одна команда `dotnet publish`.
- **Нет редактора.** Весь проект это текстовые файлы в git, поэтому его можно писать целиком через ИИ, без кликов мышкой в чужом интерфейсе.
- Пиксель-арт **генерируется кодом** при запуске. Внешних ассетов в репозитории нет.

## Ключевые решения

| Вопрос | Ответ |
| --- | --- |
| Размер карты | 512x512 в v1, цель 2048x2048 |
| Живых агентов | до 20 000 одновременно, население в цифрах — миллионы |
| Эпохи | 11 штук: палеолит -> космос |
| Длина партии | 2–3 часа при средней скорости, скорость переключается |
| Режим | чистая песочница, без целей и сценариев |
| Язык интерфейса | только русский |
| Платформа | только PC (Windows) |
| Стиль | пиксель-арт в духе WorldBox, максимум анимаций |

## Документы

1. `docs/SETUP.md` — установка окружения с нуля примерно за 30 минут.
2. `docs/DESIGN.md` — дизайн-документ: все системы мира и как они связаны.
3. `docs/PLAN.md` — план работ по 13 срезам с критериями приёмки.
4. `AGENTS.md` — правила для ИИ, который пишет код.
5. `data/eras.json` — таблица эпох и технологий, редактируется без кода.

## Быстрый старт

```
dotnet build
dotnet run --project src/WorldBox.Desktop
```

Сборка exe одним файлом:

```
dotnet publish src/WorldBox.Desktop -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

Готовый файл появится в `src/WorldBox.Desktop/bin/Release/net10.0/win-x64/publish/`.
