# Открытые вопросы

Сюда ИИ записывает спорные решения вместо того, чтобы выдумывать их самому.
Формат: вопрос, два варианта, рекомендация. Владелец отвечает одним словом.

## Отвеченные

| Вопрос | Ответ |
| --- | --- |
| Движок или фреймворк | C# + MonoGame, без редактора, сборка в exe |
| Размер карты в v1 | 512x512, 2048x2048 после S5 |
| Живых агентов | до 20 000, население числами |
| Режим игры | чистая песочница, без целей и сценариев |
| Имена и родословные | только у правителей и героев |
| Арт | процедурный пиксель-арт, генерируется кодом |
| Анимации | максимум: стройка, пожары, погода |
| Язык | только русский |
| Длина партии | 2–3 часа с переключением скорости |
| Сохранения | обязательны, моддинг позже |
| Вид сверху или изометрия | вид сверху, как в оригинальном WorldBox |
| Чужие ресурсы для эпохи | и граница, и торговый путь; путь ещё и ускоряет исследования (сделано в S5) |
| Смена дня и ночи | только визуальная, на симуляцию не влияет |
| Морские сражения | абстракция внутри войны, отдельной системы до v2 нет |
| Число стартовых племён | зависит от размера карты |
| Темп исследований | цена растёт с каждой эпохой (`research.costPerEra`) |
| Потеря эпохи | обезлюдевший народ падает на эпоху назад и сидит в тёмном веке |
| Порог тёмного века | считать по нехватке людей; `collapse.stabilityThreshold` пока не используется |
| Прибыль с сделки | деньги получают обе стороны; если казны не хватит на войска в S6 — переходим на «платит покупатель» |
| Форма торгового пути | прямая линия между городами; если будет резать глаз — изогнём её на отрисовке, а не в симуляции |
| Голод | свой склад у каждого города — с S6, иначе осада города невозможна |
| Цены | общие на весь народ: 64 народа на 10 товаров — 640 чисел, а 512 городов — уже 5120 |
| Куда тратится казна | наём войск и стройка — с S6 |
| Морская торговля | только с античности (`trade.seaEra`) |

| Вопрос | Вариант А | Вариант Б | Выбрано и почему |
| --- | --- | --- | --- |
| Клавиша окна войны | `V` | `F10` | А: окна открываются буквами (`E` народы, `G` торговля), а F-клавиши уже заняты слоями |
