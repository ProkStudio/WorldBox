# Открытые вопросы

Сюда ИИ записывает спорные решения вместо того, чтобы выдумывать их самому.
Формат: вопрос, два варианта, рекомендация. Владелец отвечает одним словом.

## Отвеченные

| Вопрос | Ответ |
| --- | --- |
| Движок или фреймворк | C# + MonoGame, без редактора, сборка в exe |
| Размер карты в v1 | 512x512, 2048x2048 после S5 |
| Живых агентов | до 20 000, население числами |
| Режим игры | чистая песочница, без целей и сценариев |
| Имена и родословные | только у правителей и героев |
| Арт | процедурный пиксель-арт, генерируется кодом |
| Анимации | максимум: стройка, пожары, погода |
| Язык | только русский |
| Длина партии | 2–3 часа с переключением скорости |
| Сохранения | обязательны, моддинг позже |
| Вид сверху или изометрия | вид сверху, как в оригинальном WorldBox |
| Чужие ресурсы для эпохи | и граница, и торговый путь; путь ещё и ускоряет исследования (сделано в S5) |

## Ждут ответа

| Вопрос | Вариант А | Вариант Б | Рекомендация |
| --- | --- | --- | --- |
| Смена дня и ночи | визуальная только | влияет на симуляцию | А, дешевле и красиво |
| Морские сражения | отдельная система | абстракция внутри войны | Б до v2 |
| Число стартовых племён | фиксированное 7 | зависит от размера карты | Б |
| Темп исследований | одна цена на все эпохи | цена растёт с каждой эпохой | Б, сейчас сделано так (`research.costPerEra`), но числа надо проверить на длинном замере |
| Потеря эпохи | эпоха не теряется никогда | обезлюдевший народ падает на эпоху назад и сидит в тёмном веке | Б, сейчас сделано так: иначе вымирание ничего не значит |
| Порог тёмного века | считать по нехватке людей (как сейчас) | считать по отдельной стабильности (`collapse.stabilityThreshold`) | А до войн, поле пока не используется |
| Прибыль с сделки | деньги получают обе стороны (как сейчас) | платит покупатель, получает продавец | А до первого замера: так проще и казна точно не уйдёт в минус; если деньги будут нужны для войск в S6 — переходим на Б |
| Форма торгового пути | прямая линия между городами (как сейчас) | поиск пути в обход гор, болот и заливов | А до S6: поиск пути на 512 маршрутов съест весь бюджет в 2 мс; если линии через горы будут резать глаз — сначала изогнём линию на отрисовке |
| Голод | считается на народ целиком (как сейчас) | свой склад у каждого города | А до войн; осада города из S6 сама потребует Б |
| Цены | общие на весь народ (как сейчас) | свои в каждом городе | А: 64 народа на 10 товаров — это 640 чисел, 512 городов — уже 5120 |
| Куда тратится казна | только надбавка к исследованиям (как сейчас) | наём войск и стройка в S6 | Б в S6: иначе богатый народ ничем не отличается от бедного в бою |
| Морская торговля | только с античности (`trade.seaEra`, как сейчас) | с любой эпохи, если есть берег | А: иначе каменный век торгует через океан и острова теряют смысл |
