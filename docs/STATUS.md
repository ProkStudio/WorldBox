# Где мы сейчас

Короткая сводка для владельца: что уже работает и что проверять руками.
Полный план срезов — в docs/PLAN.md, правила кода — в AGENTS.md.

## Срез S0 — каркас (код написан)

- Решение из шести проектов, .NET 8, MonoGame DesktopGL.
- Генератор случайных чисел, часы симуляции на 20 тиков в секунду, цикл систем с замерами.
- Камера: колесо зумит к курсору, ПКМ таскает, за край мира не уходит.
- Свой растровый шрифт с кириллицей: в репозитории нет ни одного бинарного файла.
- Оверлей F3: fps, время кадра, худший процент, время тика, год, скорость.
- Консольный замер симуляции без окна.

## Срез S1 — мир (код написан)

- Генератор: высоты с искривлением берегов, уровень моря по доле суши, температура по широте и высоте,
  влага от океана с дождевой тенью за горами, реки по реальному стоку воды, 19 биомов, плодородие, девять ресурсов.
- Режимы карты: рельеф, высоты, температура, влажность, плодородие, ресурсы.
- Отрисовка кусками 64x64: десятки вызовов за кадр вместо сотен тысяч.
- Мини-карта с рамкой вида и переносом камеры по клику.
- Панель тайла под курсором: биом, высота, градусы, влага, плодородие, ресурс.
- N — новый мир, R — пересобрать текущий сид.
- Тесты: один сид — один мир, не меньше восьми биомов, ни один биом не больше трети суши, вода течёт только вниз.

## Что проверить руками

```
dotnet build
dotnet test
dotnet run --project src/WorldBox.Desktop
```

На экране должны быть материки с реками, мини-карта в правом нижнем углу, счётчики в левом верхнем
и панель тайла внизу слева. Пока жителей нет: мир живёт, но пуст.
