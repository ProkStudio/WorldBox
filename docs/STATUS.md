# Статус проекта

Обновлено: 11 сентября 2026. Ветка `main`.

Этот файл отвечает на один вопрос: что уже есть в репозитории и что делать дальше.
Подробный план по срезам — в `docs/PLAN.md`, правила разработки — в `AGENTS.md`.

## Готово

### S0. Каркас (закрыт по коду)

- Решение `WorldBox.sln`, шесть проектов: `Core`, `Render`, `UI`, `Desktop`, `Bench`, `Tests`.
- Единый генератор случайных чисел `Rng` с сохраняемым состоянием.
- Часы симуляции: тик 20 Гц, скорости пауза/x1/x4/x16/x64, догоняющий цикл с потолком в 32 тика за кадр.
- Цикл систем `SimulationLoop` с профилированием каждой системы.
- Камера, примитивы (линии, рамки, заливка), растровый шрифт 9 px на 163 глифа, встроенный в код.
- Окно, ввод, оверлей производительности, консольный замер `WorldBox.Bench`.

### S1. Мир (закрыт по коду)

- Генератор карты: высоты через шум с материками и хребтами, уровень моря по гистограмме,
  температура по широте и высоте, влажность с переносом от океана и дождевой тенью,
  реки по стоку воды, 19 биомов, 9 видов ресурсов, плодородие с поймой.
- Отрисовка карты чанками 64x64, шесть режимов: ландшафт, высота, температура,
  влажность, плодородие, ресурсы.
- Мини-карта с прыжком по клику, панель тайла под курсором, легенда режима карты.
- Тесты: детерминизм по сиду, не менее восьми биомов, ни один биом не больше трети суши.

### S2. Арт (в работе)

- `TileArt` в ядре рисует тайлы 16x16 процедурно: не цвета, а номера оттенков 0..3.
  Десять классов поверхности (вода, лёд, песок, дюны, луга, степь, лес, камень, снег, болото),
  по четыре варианта рисунка на биом, вода анимирована четырьмя кадрами.
- `TileAtlas` собирает атлас 256x304 пикселя из оттенков и палитры биомов.
- `EdgeArt` и `TileEdgeAtlas` — рваные кромки на стыках биомов: вода наползает на песок,
  песок на траву, у берега рисуется светлая пена.
- `TileSpriteRenderer` рисует ближний план спрайтами и включается сам при зуме от 10 пикселей
  на тайл; дальше по-прежнему работает быстрый рендер чанков.
- Тесты на арт: детерминизм рисунка, диапазон оттенков, различие вариантов и кадров,
  кромка не залезает вглубь тайла.

## Чего пока нет

- Жителей, племён, поселений (срез S3).
- Эпох, технологий, экономики, религии, войн (срезы S4-S8).
- Летописи, инструментов бога, сохранений (срезы S9-S11).
- Анимаций стройки, пожаров и погоды: они описаны в `docs/ART.md`, но появятся вместе
  с объектами, которые надо анимировать.

## Как проверить

```
dotnet build
dotnet test
dotnet run --project src/WorldBox.Desktop
dotnet run -c Release --project src/WorldBox.Bench -- --ticks 5000 --size 512
dotnet publish src/WorldBox.Desktop -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

## Управление

| Клавиша | Действие |
| --- | --- |
| ПКМ или СКМ | двигать карту |
| колесо | зум |
| WASD или стрелки | шагать камерой, Shift ускоряет |
| Home | показать весь мир |
| M и Shift+M | следующий и предыдущий режим карты |
| N | новый мир |
| R | пересобрать мир на том же сиде |
| L | легенда |
| F1 | подсказка по клавишам |
| F2 | панель тайла под курсором |
| F3 | оверлей производительности |
| F4 | отключить ближний план (спрайты) |
| Пробел | пауза |
| 1-4 | скорость времени |
| Esc | выход |

## Риски

- Код писался без запуска: в песочнице нет .NET и нет сети, поэтому первая сборка на машине
  владельца может дать ошибки компиляции. Это ожидаемо и чинится по тексту ошибок.
- Ближний план рисует до нескольких десятков тысяч спрайтов за кадр. Если fps просядет,
  первый шаг — F4, второй — поднять порог `TileSpriteRenderer.MinZoom`.
- Переход на карту 2048x2048 делаем только после среза S5 и только если тик укладывается в 6 мс.
