**Важно.** Весь код написан без компиляции: в песочнице агента нет .NET и нет сети, поэтому `dotnet build` ни разу не запускался. Первая сборка — за владельцем. Если вылезут ошибки компиляции, пришли первые 10-20 строк вывода `dotnet build`, они правятся быстро.

## Что готово

### S0 — каркас и окно

- Решение `WorldBox.sln`: `Core`, `Render`, `UI`, `Desktop`, `Bench`, `Tests`. `Core` не знает про MonoGame.
- Свой генератор случайных чисел `Rng` (xoshiro-подобный, с сохранением состояния) — единственный источник случайности в симуляции.
- Часы симуляции: тик 20 Гц, скорости `Пауза / x1 / x4 / x16 / x64`, догон отставания с ограничением 32 тиков за кадр.
- Цикл систем `SimulationLoop` с профилировкой каждой системы по миллисекундам.
- Окно 1600x900, камера с зумом и панорамой, оверлей с fps, миллисекундами кадра, тиком и годом.
- Пиксельный шрифт 9 px на 163 глифа, зашитый в код в base64 — бинарных ассетов в репозитории нет.
- Консольный прогон `WorldBox.Bench` для замеров без окна.

### S1 — мир

- Генератор мира: континенты на шумах, горные хребты, температура по широте и высоте, влажность с переносом от океана и дождевой тенью, стоки рек по склону, плодородие, 19 биомов, 10 видов ресурсов.
- Карта хранится массивами по полям (SoA), контрольная сумма карты считается для тестов детерминизма.
- Отрисовка чанками 64x64 с ленивой перестройкой, 6 режимов карты: ландшафт, высота, температура, влажность, плодородие, ресурсы.
- Мини-карта с прыжком по клику, панель тайла под курсором, легенда биомов и ресурсов.
- Тесты: детерминизм по сиду, не меньше 8 биомов, ни один биом не занимает больше трети суши, генерация 512x512 быстрее 3 секунд.

### S2 — тайлсет и ближний план

- Процедурные тайлы 16x16: 10 классов поверхности, по 4 варианта на класс, вода анимирована 4 кадрами, 4 оттенка яркости. Всё считается кодом при запуске, картинок в репозитории нет.
- Атлас текстур собирается один раз на старте карты.
- На близком зуме (от 10 пикселей на тайл) карта рисуется спрайтами из атласа, дальше — цветными чанками.
- Маски переходов между биомами: у берега пена, у границ биомов мягкая кромка с приоритетом по типу поверхности.
- `F4` выключает ближний план, если на слабом железе просядет fps.

### S3 — жители (первый проход)

- Хранилище `Population`: массивы координат, возраста, голода и народа, ёмкость по умолчанию 20 000, свободные слоты переиспользуются, плотность по тайлам обновляется сразу при рождении, переезде и смерти.
- Расселение на старте: 400 человек только на суше и тем охотнее, чем плодороднее тайл, поэтому старт получается в поймах и на лугах.
- Система `PopulationSystem` за один тик (5 игровых лет): старение, еда по плодородию с учётом тесноты, голод, переезд на соседний тайл получше, роды у взрослых, смерть от старости и от голода.
- Ноль аллокаций за тик, никаких списков и LINQ, вся случайность из `world.Rng` — партия повторяется по сиду.
- Отрисовка точками: цвет от сытости (светлый — сыт, красный — голодает), на близком зуме под точкой тёмная подложка. `F5` прячет людей.
- Тесты: рождение/смерть/переезд не ломают плотность, ёмкость соблюдается, все люди всегда на суше и в границах, 120 тиков дают одинаковую контрольную сумму на одинаковом сиде, население живо после 200 тиков.

## Чего ещё нет

- Счётчика населения в оверлее и тепловой карты плотности на дальнем зуме — следующий шаг.
- Племён, границ, поселений, технологий и эпох (срезы S4 и дальше).
- Экономики, религии, культуры, войн, катастроф, летописи, сохранений.
- Спрайтов человечков с анимацией ходьбы — появятся вместе с занятиями и племенами.
- Подсказка `F1` не упоминает клавиши `L`, `F4` и `F5`: строки в `data/strings.ru.json` ещё не дописаны.

## Как проверить

```
dotnet build
dotnet test
dotnet run --project src/WorldBox.Desktop
dotnet run -c Release --project src/WorldBox.Bench -- --ticks 5000 --size 512
dotnet publish src/WorldBox.Desktop -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

Последняя команда даёт один `WorldBox.exe`, который запускается двойным кликом без установленного .NET.

## Клавиши

| Клавиша | Что делает |
| --- | --- |
| `Esc` | выход |
| `F1` | подсказка по управлению |
| `F2` | панель тайла под курсором |
| `F3` | оверлей с fps и годом |
| `F4` | ближний план спрайтами вкл/выкл |
| `F5` | жители вкл/выкл |
| `L` | легенда |
| `M` / `Shift+M` | следующий / предыдущий режим карты |
| `N` | новый мир |
| `R` | тот же мир заново |
| `Space` | пауза |
| `1` `2` `3` `4` | скорость x1, x4, x16, x64 |
| `Home` | показать весь мир |
| Колесо | зум к курсору |
| ПКМ или СКМ | панорама |
| `WASD` / стрелки | сдвиг камеры, с `Shift` быстрее |
| ЛКМ по мини-карте | прыжок камеры |

## Риски

1. Код не компилировался ни разу. Самые вероятные места ошибок: перегрузки `SpriteBatch.Draw`, порядок членов перечисления `Biome` в таблице тайлов, имена свойств в `BiomeLegend`.
2. Баланс населения черновой: числа в `PopulationSettings` подобраны на глазок, население может расти быстрее или медленнее задуманного. Правится одним файлом.
3. Отрисовка людей идёт полным проходом по всем слотам каждый кадр. До 20 000 человек это дёшево, но на больших числах понадобится разбиение по чанкам.
4. Переход на карту 2048x2048 — только после среза S5, как записано в `docs/PLAN.md`.
